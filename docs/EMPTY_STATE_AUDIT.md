# تدقيق الحالات الفارغة — قراءة فقط

هذا التدقيق مبني على قراءة الكود بعد ربط SQLite. لم تُضف عناصر واجهة ولم يُغيّر أي نص لهذا التدقيق.

| الحالة | الموضع المقروء | النتيجة الحالية |
|---|---|---|
| صفر ملاحظات | `app/notes.tsx`، `FlatList.ListEmptyComponent` | يعرض أيقونة `StickyNote` والنص `لا توجد ملاحظات بعد، اضغط + للبدء`. لا يوجد اعتماد على عنصر أول. |
| نتيجة بحث فارغة | `app/notes.tsx`، نفس `ListEmptyComponent` | عند وجود `search` يعرض `لا توجد نتائج مطابقة`. البحث لا يقرأ undefined لأن `notes` مصفوفة جاهزة. |
| شرائح المجلدات | `app/notes.tsx` و`HorizontalScrollRow` | «الكل» و«غير مصنف» يُرسمان من عناصر واجهة افتراضية، وقائمة المجلدات الفعلية الفارغة لا تكسر الصف. |
| صفر مجلدات فعلية | `app/folders.tsx` | يبقى «الكل» و«غير مصنف» و«مجلد جديد»؛ العداد يأتي من `noteCounts` ويعود إلى 0. لا توجد صفوف seed. |
| قائمة النقل بلا مجلدات | `app/notes.tsx:MoveNoteModal` | `ScrollView` فارغ، ويظل «غير مصنف» وأزرار «حذف» و«إلغاء» مرئية. لا يظهر `undefined`. |
| صفر مهام — كل فلتر | `app/tasks.tsx` و`ListEmptyComponent` | يعرض `لا توجد مهام` للكل، `لا توجد مهام غير منجزة` لفلتر المفتوحة، و`لا توجد مهام منجزة` للفلتر المنجزة. |
| سلة فارغة | `app/recycle-bin.tsx` | يعرض أيقونة `Recycle` والنص `سلة المحذوفات فارغة`. |
| المساعد بلا ملاحظات في النطاق | `app/assistant.tsx` | تظهر رسالة البداية والاقتراحات. لا يعتمد عرض الرسائل على وجود ملاحظة. حالة المفتاح المفقود تعرض بطاقة الإعدادات؛ الرد المحاكي يعالج عدم وجود الملاحظة المصدر. |
| استخراج من ملاحظة بلا نص | `app/note/[id].tsx` | `extract` يفحص `note.body.trim()` قبل فتح النافذة ويعرض Alert `اكتب نصًا في الملاحظة أولاً`. |
| بيانات تحميل غير متاحة | `app/_layout.tsx` و`AppStateProvider` | Splash يمنع رسم الشاشات حتى جاهزية SQLite والبيانات. فشل الفتح/الترحيل أو تحميل repositories يعرض شاشة خطأ نصية بدل الانهيار. |

## اقتراحات غير منفذة

لم تظهر من القراءة حاجة لإضافة حالة فارغة جديدة؛ كل الحالات المطلوبة لها مسار عرض حالي، لذلك لم تُضف عناصر أو نصوص حفاظًا على الواجهة المغلقة.

## حدود التحقق

هذا فحص ساكن بالقراءة فقط. لم تُرسم الحالات على جهاز Android فعلي، ولم تُختبر قاعدة SQLite على تثبيت نظيف داخل Expo Go من بيئة Sandbox.
